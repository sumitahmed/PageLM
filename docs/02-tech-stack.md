# 02 — Technology Stack Inventory

This document provides a comprehensive inventory of all tools, libraries, runtimes, and frameworks used across PageLM. For every component, it explains **what the technology is doing inside PageLM**, rather than merely offering an abstract definition.

---

## 1. Frontend Technologies

| Category | Technology | Version | Purpose in PageLM |
| :--- | :--- | :--- | :--- |
| **UI Framework** | **React** | `^19.2.7` | Powers the single-page application. Manages component lifecycles, user interactions, local states, and DOM updates across all views. |
| **Language** | **TypeScript** | `~5.9.3` | Enforces compile-time type safety across UI props, API response types, and WebSocket event payloads. |
| **Bundler & Dev Server** | **Vite** | `^7.3.5` | Provides rapid local development with Hot Module Replacement (HMR) and bundles optimized production assets into `dist/`. |
| **CSS & Styling** | **Tailwind CSS** | `^4.3.0` | Utility-first CSS engine used for styling the dark-mode user interface, layouts, transitions, and responsive grid layouts. |
| **Routing** | **React Router DOM** | `^7.17.0` | Client-side routing engine mapping browser paths (`/`, `/chat`, `/quiz`, `/tools`, `/planner`, `/debate`, `/cards`, `/exam`) to specific page components. |
| **UI & Error Handling** | **@cognicatch/react** | `^1.2.2` | Provides `AdaptiveToastProvider` for pop-up toast notifications and `AdaptiveErrorBoundary` to handle input component failures gracefully. |
| **Force-Directed Graph** | **d3-force** | `^3.0.0` | Computes physics-based node positioning and collision detection for the interactive mindmap in the Homework Planner (`PlannerMindmap.tsx`). |
| **Markdown Rendering** | **react-markdown** | `^10.1.0` | Renders AI answers into structured HTML containing headers, lists, tables, and code blocks. |
| **GFM Extension** | **remark-gfm** | `^4.0.1` | Enables GitHub Flavored Markdown support (tables, strikethrough, autolinks) in Markdown views. |
| **Line Breaks** | **remark-breaks** | `^4.0.0` | Ensures soft line breaks in user or AI text render as `<br>` tags rather than collapsing into single lines. |
| **LaTeX Math** | **remark-math** & **rehype-katex** | `^6.0.0` / `^7.0.1` | Detects LaTeX formulas (inline `$...$` and block `$$...$$`) and renders beautiful mathematical equations via KaTeX. |
| **Syntax Highlighting** | **rehype-highlight** & **highlight.js** | `^7.0.2` / `^11.11.1` | Formats and highlights code snippets generated by AI in programming-related queries. |
| **HTTP & Networking** | **Native Fetch API** | Browser Built-in | Handles asynchronous REST requests to backend endpoints with custom timeout wrapping via `AbortController`. |
| **Realtime Networking** | **Native WebSocket API** | Browser Built-in | Connects to backend WebSocket routes (`/ws/chat`, `/ws/quiz`, `/ws/planner`, etc.) for live generation progress and token streaming. |

## 2. Backend Technologies

| Category | Technology | Version | Purpose in PageLM |
| :--- | :--- | :--- | :--- |
| **Runtime** | **Node.js** | `>=21.18.0` | Executes the backend server. Requires Node 21+ to leverage native `process.loadEnvFile` without external packages like dotenv. |
| **Language** | **TypeScript** | `^5.8.3` | Provides end-to-end typing for backend services, agent tools, LangGraph annotations, and database models. Transpiled via `tsc` to CommonJS. |
| **Web Server Engine** | **Fubelt Server** (`utils/server/server.js`) | Custom (Cavira OSS) | A zero-dependency web server built directly on Node's native `http` module and `ws`. Replaces Express for lightweight route matching, parameter extraction, and WebSocket upgrades. |
| **WebSocket Engine** | **ws** | `^8.18.3` | Powers bidirectional WebSocket connections for real-time streaming of chat answers, quiz cards, audio progress, and debate analysis. |
| **CORS Middleware** | **cors** | `^2.8.5` | Configures Cross-Origin Resource Sharing headers to allow the Vite dev server (`:5173`) to communicate with the API (`:5000`). |
| **File Upload Streaming**| **busboy** | `^1.6.0` | High-performance streaming parser for incoming `multipart/form-data` requests (document uploads and audio recordings). |
| **Key-Value Persistence**| **keyv** & **@keyv/sqlite** | `^5.5.1` / `^4.0.5` | Stores chat metadata, message history, flashcards, planner tasks, and debate sessions backed by `storage/database.sqlite`. |
| **PDF Text Extraction** | **pdf-parse** | `^1.1.1` | Extracts raw text from user-uploaded PDF study documents for embedding into the RAG vector store. |
| **PDF Generation** | **pdf-lib** & **@pdf-lib/fontkit** | `^1.17.1` / `^1.1.1` | Programmatically creates and fills Cornell notes PDF files using custom embedded fonts (`Lexend.ttf`). |
| **Word Doc Extraction** | **mammoth** | `>=1.11.0` | Extracts raw, clean text from `.docx` and OpenDocument files without external Office dependencies. |
| **Markdown Parsing** | **marked** | `^16.3.0` | Converts uploaded Markdown files into plain text before chunking and embedding. |
| **DOCX Templates** | **docxtemplater** & **pizzip** | `^3.66.7` / `^3.2.0` | Available for ZIP-based Word template manipulations and document assembly. |

## 3. AI, RAG & Audio Technologies

| Category | Technology | Version | Purpose in PageLM |
| :--- | :--- | :--- | :--- |
| **AI Framework** | **LangChain** | `^1.4.4` | Core AI interface providing base abstractions for chat models, prompts, documents, and embeddings. |
| **State Machine Agents** | **@langchain/langgraph** | `^1.3.7` | Powers the **ExamLab** engine using a `StateGraph` state machine (`load` → `cache` → `gen` → `validate` → `save`). |
| **Text Chunking** | **@langchain/textsplitters** | `^1.0.1` | Splits extracted text into semantic chunks (`chunkSize: 512, chunkOverlap: 30`) using `RecursiveCharacterTextSplitter`. |
| **In-Memory Vector Store**| **@langchain/classic** | `^1.0.34` | Provides `MemoryVectorStore` to load document embeddings on the fly for the default `db_mode=json` configuration. |
| **Persistent Vector Store**| **@langchain/community** (`Chroma`) | `^1.1.29` | Connects to an external Chroma vector database instance when configured with `db_mode=chroma`. |
| **Google Gemini** | **@langchain/google-genai** | `^2.1.31` | Implements LLM generation (`gemini-2.5-flash` / `gemini-1.5-pro`) and embeddings (`text-embedding-004`). |
| **OpenAI** | **@langchain/openai** & **openai** | `^1.4.7` / `^6.8.1` | Implements GPT-4o-mini, text embeddings (`text-embedding-3-large`), Whisper transcription (`whisper-1`), and study guide synthesis. |
| **Anthropic Claude** | **@langchain/anthropic** | `^1.4.0` | Connects PageLM to Anthropic's Claude 3.5 Sonnet model family. |
| **Local LLMs (Ollama)** | **@langchain/ollama** | `^1.2.7` | Connects PageLM to locally hosted models (e.g., `llama4`, `llama3`) and local embeddings for offline use. |
| **Edge Text-to-Speech** | **node-edge-tts** | `^1.2.8` | Synthesizes free, high-quality neural speech via Microsoft Edge's speech service without requiring an API key. |
| **ElevenLabs TTS** | **Direct REST API** | Custom fetch | Generates ultra-realistic voice segments using ElevenLabs' Multilingual v2 models. |
| **Google Cloud TTS** | **@google-cloud/text-to-speech** | `^6.3.0` | Cloud text-to-speech client synthesizing audio with Google Neural2 voices. |
| **Multi-Cloud Speech SDK**| **@speech-sdk/core** | `^0.15.0` | Dynamically imported ESM library providing unified dialogue synthesis across 14 voice providers (Cartesia, Deepgram, MiniMax, Hume, etc.). |
| **Audio Concat Engine** | **FFmpeg** | System CLI | Invoked via Node's `child_process.spawn` to stitch individual speaker audio files into a unified podcast MP3. |
| **Speech-to-Text (STT)** | **Whisper / Google / AssemblyAI / ElevenLabs** | Mixed SDK/REST | Transcribes recorded or uploaded audio into text with confidence scoring. |

## 4. Infrastructure & DevOps

| Component | Tool | Purpose in PageLM |
| :--- | :--- | :--- |
| **Container Engine** | **Docker** | Encapsulates both backend and frontend environments with reproducible dependencies. |
| **Container Orchestration** | **Docker Compose** | Manages multi-container orchestration (`pagelm-backend` on port 5000 and `pagelm-frontend` on port 5173) with volume persistence for `storage/`. |
| **Backend Docker Image** | `node:22.16.0-alpine` | Lightweight Linux container using multi-stage build (`base` → `builder` → `runtime`). |
| **Frontend Docker Image** | `node:22.16.0-alpine` + `pnpm` + `serve` | Builds React static files using pnpm and serves the production bundle using `serve -s dist -l 5173`. |
| **Continuous Integration** | **GitHub Actions** (`ci.yml`) | Validates TypeScript builds, installs dependencies with pnpm/npm, executes security audits, and runs test Docker builds on pull requests. |
| **Security Scanning** | **GitHub Actions** (`security.yml`) | Performs dependency vulnerability scans and secret checks. |
| **Hot Reloading** | **Nodemon** & **tsx** | Automatically monitors backend code modifications in `backend/src` and restarts the development server without manual recompilation. |
